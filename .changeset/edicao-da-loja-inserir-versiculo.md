Adds a store (sandboxed) edition for the EmDash Marketplace with an **Insert verse** editor panel: type a reference, pick a version, and the passage is added as a quote at the end of the entry's text, with the version credit. The store edition has no hover tooltip (EmDash runs `page:fragments` only for trusted plugins); the trusted npm install keeps the tooltips unchanged.

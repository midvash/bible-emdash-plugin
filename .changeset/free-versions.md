Only versions the Midvash API serves. Since October 2026 the API serves openly licensed versions only: a request for NVT, NAA, NIV, NLT, NTV, RVR1960… returns a free version's text, so tooltips showed "NVT" over Open Nova Bíblia Viva text. The admin now lists the 23 free versions for pt-BR / en / es, and a saved version the API dropped switches to the one it serves in its place (NVT → ONBV, NLT → BSB, NTV → ONBV, NAA → Bíblia Livre) in the links, the lookups and the admin form, with no action needed. The tooltip badge names the version that was actually served, and the footer shows its credit (title · license), which CC BY versions require. New defaults: Bíblia Livre (pt-BR), KJV (en), RVR1909 (es).
